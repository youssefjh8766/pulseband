# pulseband
wearable activity tracking and calorie buring and sleeping
The nRF52840-based activity tracker utilizes a MAX30102 biometric sensor and BMI270 IMU to monitor movement and sleep cycles. Housed in a compact, 3D-printed enclosure, the device integrates a 300mAh LiPo battery, haptic feedback, and magnetic charging contacts for continuous data logging.
